1 задание. 
@Invoke.
Разработайте аннотацию @Invoke, со следующими характеристиками:
• Целью может быть только МЕТОД
• Доступна во время исполнения программы
• Не имеет свойств
Создайте класс, содержащий несколько методов, и проаннотируйте хотя бы один из них аннотацией @Invoke.
Реализуйте обработчик (через Reflection API), который находит методы, отмеченные аннотацией @Invoke, и вызывает их автоматически.
Была разработана аннотация @Invoke со следующими свойствами:
•	может применяться только к методам (@Target(ElementType.METHOD));
•	доступна во время выполнения программы (@Retention(RetentionPolicy.RUNTIME));
•	не содержит параметров.
Создан класс TestClass с несколькими методами. Некоторые из них отмечены аннотацией @Invoke.
Создан обработчик InvokeHandler, который перебирает все методы и вызывает автоматически отмеченные @Invoke. Затем вызываются все методы вручную для сравнения.
Пример:
Автоматический вызов методов с @Invoke: 
Метод 1 вызван!
Метод 3 вызван!
Ручной вызов всех методов для сравнения: 
Метод 1 вызван!
Метод 2 вызван!
Метод 3 вызван!

3 задание.
@ToString.
Разработайте аннотацию @ToString, со следующими характеристиками:
• Целью может быть ТИП или ПОЛЕ
• Доступна во время исполнения программы
• Имеет необязательное свойство valuec двумя вариантами значений: YES или NO
• Значение свойства по умолчанию: YES
Проаннотируйте класс аннотацией @ToString, а одно из полей – с @ToString(Mode.NO).
Создайте метод, который формирует строковое представление объекта, учитывая только те поля, где @ToString имеет значение YES.
Создана аннотация @ToString, которая имеет следующие характеристики:
•	применяется к классам и полям (TYPE, FIELD);
•	доступна во время выполнения (RUNTIME);
•	содержит необязательное свойство value, принимающее значения YES или NO;
•	значение по умолчанию — Mode.YES.
Дополнительное перечисление Mode.
Создан класс с аннотациями TestClass3:
•	сам класс помечен @ToString, в котором по умолчанию YES;
•	некоторые поля имеют @ToString(Mode.YES);
•	некоторые поля исключены из строкового представления @ToString(Mode.NO).
Создан обработчик ToStringHandler:
•	Получает все поля класса.
•	Проверяет, помечено ли поле аннотацией @ToString.
•	Включает поле в строку только если указано Mode.YES.
Пример:
Демонстрация аннотации @ToString: 
Все поля объекта:
name: Karina
age: 19
email: karina@mail.com
salary: 100000.0
Строковое представление: TestClass3{name=Karina, email=karina@mail.com}
Поля age и salary — исключены согласно аннотации.

• Целью может быть ТИП
• Доступна во время исполнения программы
• Имеет необязательное свойство value, типа String[]
• Значение свойства по умолчанию: пустой массив
Проаннотируйте класс аннотацией @Cache, указав несколько кешируемых областей.
Создана аннотация @Cache со следующими требованиями:
•	Цель аннотации — ТИП (класс, интерфейс).
•	Аннотация должна быть доступна во время выполнения программы (runtime).
•	Иметь необязательное свойство value типа String[].
•	Значение по умолчанию — пустой массив.
•	Реализовать обработчик, который выводит содержимое кешируемых областей или сообщение об отсутствии данных.
Классы, аннотированные @Cache

•	Проверяет, есть ли аннотация @Cache у класса.
•	Если есть — извлекает value().

•	Если аннотации нет — сообщает об отсутствии.
